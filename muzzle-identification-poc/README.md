# Muzzle Identification POC

This repository contains a Proof of Concept for cow muzzle identification. It includes a mobile Flutter app, a Python backend (FastAPI), model/artifacts directories, scripts, and docs.

Structure:
- mobile/flutter_app - Flutter application
- backend - FastAPI backend and AI services
- models - trained model artifacts (YOLO, ResNet, FAISS)
- storage - uploads, processed images, embeddings
- scripts - training and indexing scripts
- docs - documentation
- tests - basic test scaffolding

Use docs/setup.md to get started.
